🪪 Meu perfil no Firestore

Cada conta possui um perfil particular. A opção motorista aqui é autodeclarada para testes, não é uma aprovação profissional.

As tarifas desta Conta e do Painel são as mesmas. A base e as tarifas são restauradas do servidor antes de permitir alterações.

Cadastro e login são feitos diretamente no Firebase Authentication, sem gravar senhas no Firestore ou neste HTML. Ative o provedor E-mail/Senha no console Firebase. O painel integrado permite enviar corridas de teste com coordenadas de embarque e destino. O acesso depende das regras do Firestore; o GPS do motorista não é compartilhado.

📡 Corridas entre dois celulares — TESTE

Teste integrado ao Firestore. Use duas contas diferentes. Usa Authentication e Firestore, sem Cloud Functions.
